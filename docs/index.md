# MyUNO Capital — Documentation

Welcome to the documentation for **MyUNO Capital**, the Autonomous AI Operating System for solo entrepreneurs that covers the full business lifecycle — **idea → validation → build → grow → scale → exit**.

This is the documentation home. Each document below covers one area of the platform. New here? Start with the [Overview](overview.md), then follow the [Getting Started guide](getting-started.md) to run the stack locally.
